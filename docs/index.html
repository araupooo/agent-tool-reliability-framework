Agent Tool Reliability Framework — Findings

Map timeout, cancellation, and partial-failure propagation across three agent-tooling components, replay a network-scale corpus deterministically, and measure recovery with deterministic assertions for preserved results, reported errors, and zero silent drops. The record/replay core is reused verbatim from the parallel-tool-replay-harness (harness/, the seven asyncio scenarios, the shell runner); the thread-pool dispatcher, the 48-trace corpus, the 36-cell fault-injection matrix, and the propagation map are new in this framework. Every assertion is deterministic: a virtual clock replaces wall-clock time, so a replayed trace is byte-identical to the recorded one.

Reproduce

bash scripts/run_all.sh outputs/run1
bash scripts/clean_reproduce.sh   # fresh-copy run; must match run1 byte-for-byte
bash scripts/verify_digests.sh    # verifies SHA256SUMS

Requirements: Python 3.11+ (standard library only), GNU bash 5.1+ (wait -n -p), sha256sum. No network access, no credentials.

Components validated

  1. Asyncio parallel tool dispatcher (harness/): Python asyncio dispatcher running batches of parallel tool calls on a virtual clock; semantics follow the OpenAI function-calling guide (multiple calls per turn, matched by call_id) and the Anthropic parallel-tool-use guide (one tool_result per tool_use block, matched by tool_use_id).
  2. Shell parallel runner (components/shell_runner/): the same trace schema applied to real concurrent shell processes (background jobs, wait -n completion order, exit codes, output digests).
  3. Threaded thread-pool dispatcher (components/threaded_dispatcher/): models Python's concurrent.futures.ThreadPoolExecutor on the same virtual clock — worker slots, FIFO queue, Future.cancel() semantics, collector wait() timeout with late-result reconciliation — verified against the CPython source and a live probe with a real executor.
  4. Reference implementation inspection: CorbanuTerminal's parallel tool runtime (codex-rs/core/src/tools/parallel.rs, commit 7b5b368f): parallel-execution gate, CancellationToken abort path, nested-call timing guard, 3-per-turn identical-call cap.
